# Честный выбор 18+

Локальное приложение с персональными дилеммами, несколькими профилями, честной статистикой и настраиваемым интерфейсом.

## Что изменилось

- полностью новый тёмный интерфейс приложения;
- создание профиля по имени и фамилии с проверкой формата;
- отдельная случайная последовательность вопросов для каждого профиля;
- алгоритмический генератор по теме, формату и уровню жёсткости;
- отсутствие выдуманных участников и голосов;
- локальная таблица участников с ответами, серией и совпадением с большинством;
- история ответов и сохранение вопросов;
- темы, акцентные цвета, размер текста, компактный режим и отключение анимаций;
- фильтр контента 18+, приватное отображение фамилии;
- экспорт и импорт всех локальных данных в JSON.

> Без сервера невозможно подтвердить настоящее имя документами или показать общую таблицу посетителей со всего интернета. Приложение проверяет формат имени, а таблица содержит только профили, созданные в текущем браузере. Это явно обозначено в интерфейсе.

## Запуск без установки

1. Нажмите **Code → Download ZIP** на странице репозитория.
2. Распакуйте архив.
3. Дважды нажмите `index.html`.

Python, Node.js, терминал и интернет после скачивания не нужны.
