# ЧЕСТНО — локальные дилеммы 18+

Настраиваемое веб-приложение со случайными персональными вопросами, локальными профилями и честной статистикой.

## Что изменено

- полностью новый тёмный интерфейс приложения;
- пять акцентных цветов, три темы, масштаб, форма карточек, анимации и компактный режим;
- случайная алгоритмическая генерация вопросов для каждого профиля;
- вопросы не повторяются в пределах истории профиля;
- локальная таблица реальных участников;
- отдельная история и статистика каждого человека;
- никаких стартовых, тестовых или выдуманных голосов;
- данные сохраняются только в `localStorage` текущего браузера.

## Важно о «реальных» данных

У приложения нет сервера. Поэтому таблица показывает только людей, которые создали профиль и голосовали **на этом устройстве в этом браузере**. Сайт намеренно не показывает выдуманные имена, голоса или проценты. Для общей таблицы посетителей с разных устройств потребуется подключить внешнюю базу данных.

## Запуск без установки

1. Нажмите **Code → Download ZIP**.
2. Распакуйте архив.
3. Дважды нажмите файл `index.html`.

Python, Node.js и терминал не нужны. Все основные функции работают локально и офлайн.
