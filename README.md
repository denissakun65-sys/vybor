## О проекте

«Честный выбор» — локальное приложение с персональными вопросами 18+. У каждого профиля свой неповторяющийся набор дилемм. В статистике учитываются только ответы людей, создавших профиль в этом браузере: выдуманных участников и заранее нарисованных процентов нет.

> **Важно:** приложение работает без сервера. Оно может проверить формат имени, но не способно подтвердить личность по документам. Таблица участников является локальной и не объединяет посетителей с разных устройств.

## Возможности

| Раздел | Что умеет |
|---|---|
| **Дилеммы** | Отдельная случайная очередь для каждого профиля, учёт показанных и пропущенных вопросов |
| **Генератор** | Темы, три уровня жёсткости и три формата вопроса |
| **Участники** | Имя, количество ответов, серия, совпадение с локальным большинством |
| **История** | Все реальные ответы текущего профиля с датой и выбранным вариантом |
| **Настройки** | Тема, пять акцентов, размер текста 90–125%, компактный режим, анимации и приватность |
| **Данные** | Экспорт и импорт JSON, полная очистка локального хранилища |
| **Управление** | Клавиши `1` и `2` для ответа, `N` для следующего вопроса, `S` для настроек |

## Честная статистика

- Первый голос отображается как **100 / 0**, а не дополняется выдуманными значениями.
- Показанный или пропущенный сюжет не появляется повторно до завершения всего набора.
- Интерфейс показывает, сколько уникальных сюжетов осталось.
- После исчерпания набора приложение явно сообщает о начале нового круга.
- Данные каждого профиля хранятся в `localStorage` текущего браузера.

## Запуск без установки

1. Нажмите зелёную кнопку **Code** на странице репозитория.
2. Выберите **Download ZIP**.
3. Распакуйте архив.
4. Дважды нажмите файл `index.html`.

Python, Node.js, терминал и интернет после скачивания не нужны.

## Конфиденциальность

Приложение не отправляет имена, вопросы или ответы на внешний сервер. Удаление данных через настройки очищает локальные профили на текущем устройстве. Для переноса можно использовать экспорт и импорт JSON.
