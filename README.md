# ВЫБОР

Интерактивный сайт с дилеммами, анонимными голосованиями и локальным генератором новых вопросов.

## Возможности

- 30 готовых вопросов в шести категориях;
- результаты голосования сразу после ответа;
- личная статистика в `localStorage`;
- рейтинг вопросов с результатом около 50/50;
- генератор новых дилемм без внешнего API;
- адаптивная вёрстка и оригинальные SVG-иконки;
- публикация на GitHub Pages из ветки `main`.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Добавьте его как remote и отправьте ветку `main`:

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

3. В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. После публикации адрес сайта появится в разделе **Deployments**.

Весь сайт статический: сервер, база данных и API-ключи не требуются.
